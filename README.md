# Competitive Programming — C++

A personal archive of C++ solutions and practice from programming contests and online judges.

## Coverage

The original folder is preserved by contest platform and source:

- `Atcoder/` — AtCoder problems
- `codeforce/` — Codeforces problems and study tracks
- `zerojudge/` — ZeroJudge problems
- `CSES/`, `JOI/`, `USACO/`, `APCS/`, `toij/`, `ntucpc/`, `OnlineJudge/`, `Library Checker/`, and other contest folders

The collection contains more than 400 C++ source files. It is a working practice archive; not every solution is guaranteed to be final, accepted, or optimized.

## Build a solution

Most files are standalone C++17 programs:

    g++ -std=c++17 -O2 -Wall -Wextra path/to/solution.cpp -o solution
    ./solution

Some problems require standard input or accompanying special-judge files.

## Public-repository cleanup

Compiled binaries, debugger bundles, IDE settings, helper metadata, and the incomplete file that depended on a missing `lib2249.h` were excluded. The original local source folder was not modified.
